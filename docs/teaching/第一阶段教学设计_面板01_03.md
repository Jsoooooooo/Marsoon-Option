# 期权看板 · 第一阶段教学设计（面板 01 Overview + 03 Positioning）

> 对应框架：[Marsoon-Option](https://github.com/Jsoooooooo/Marsoon-Option)（Next.js + React 期权看板）
> 教学形式：单文件交互式幕布 HTML（双击即开，无 CDN、无构建），遵循 `animated-curtain-teaching.txt` 规范

## 0. 教学定位

- 对象：零基础小白（不懂期权、不写代码，第一次打开看板）。
- 目标：看完本讲（约 8 分钟），能独立读懂面板 01 Overview 与面板 03 Positioning，并说出"先看 01 定方向、再用 03 验证"。
- 边界：本讲只教"看什么、怎么读"，不涉及代码实现；数据全部为教学示意，真实接入按 `options-dashboard-frontend-integration.md` 的口径执行。

## 1. 学习目标（学完能回答三个问题）

1. 01 Overview 里的 Gamma Regime、Call/Put Wall、Gamma Flip、Expected Move 分别是什么、怎么读？
2. 03 Positioning 里的 OI 蝴蝶图、ΔOI、Volume、P/C 比在说什么？
3. 两个面板怎么配合使用？

## 4. 术语注释清单（Hard Rule：全覆盖、可发现）

约定：HTML 正文用 `.kw`（虚线下划线），SVG 元素用 `.hot`（文字虚线下划线 / 框虚线描边）；封面与底部提示条各说明一次约定。每个缩写首次出现在每幕时都带 `data-tip`。

| 术语 | 白话解释（data-tip 文案） |
| --- | --- |
| 期权 | 一种合约：约定一个价格和时间，给你「涨/跌」的选择权。 |
| Call | 看涨期权：价格越高越值钱，相当于一张「涨价合同」。 |
| Put | 看跌期权：价格越低越值钱，相当于一份「保险」。 |
| Strike（行权价 K） | 合同里写死的价格；涨过它 Call 才开始赚，跌破它 Put 才开始赚。 |
| Spot | 标的（股票/指数）当前的报价。 |
| OI（未平仓合约） | 市场上「还活着」的合约总张数：开仓 +1、平仓 -1、换手不变。 |
| ΔOI | 今日新增持仓（今日入库量）：绿=加仓、红=减仓。 |
| Volume | 今日成交总张数（含开仓/平仓/换手），反映「热闹程度」。 |
| 蝴蝶图 | 每个行权价一根柱子的持仓分布图，像蝴蝶两翼。 |
| Dealer（做市商） | 交易所里负责接单的「柜台」；看板假设它是对手方。 |
| 对冲 | 柜台接了单后，去现货市场反向买卖「垫一层」来防亏损。 |
| Gamma | 「价格每动 1 点，柜台需要加多少对冲」的敏感度。 |
| 正 Gamma | 柜台「涨了卖、跌了买」→ 把价格拉回原处（弹簧床）。 |
| 负 Gamma | 柜台「涨了买、跌了卖」→ 推着价格越走越远（雪球）。 |
| Regime | 市场当前所处的状态（正 Gamma / 负 Gamma / 中性）。 |
| GEX | 全部期权行权价对冲力量的汇总（OI 模型口径），单位 $/1% 波动。 |
| Call Wall | 上方最大 Call 持仓堆积位，价格涨到那里被「压」住。 |
| Put Wall | 下方最大 Put 持仓堆积位，价格跌到那里被「托」住。 |
| Gamma Flip | 净 GEX 由正转负的价位；教学中简化为：价在其上=正 Gamma 区、其下=负 Gamma 区。 |
| Max Γ | 单一行权价净 GEX 峰值 = 最强引力位。 |
| Expected Move | 按当前波动率推算的今日大概波动区间。 |
| IV（隐含波动率） | 市场「预期」的波动大小，IV 越高预期越激烈。 |
| IV Rank | 当前 IV 在历史中的百分位；当前后端未提供 → 显示 `--`。 |
| ATM | 最接近当前价格的行权价（平值）。 |
| P/C 比 | Put 量 ÷ Call 量；<1 偏 Call（看涨仓多），>1 偏 Put。 |

## 5. 交互与视觉设计要点（按 skill 规范）

- 每幕一个 `<button>` demo，点击驱动 SVG 状态变化（柱高、标记位移、箭头点亮、文字变绿/红），`button.blur()` 防止空格误翻页。
- 通俗类比以「对照表」形式与示意图同屏堆叠（不隐藏任一），第一列为维度名，斑马纹、1px 边框（类 Excel 观感）。
- 每侧动态读数放在各自卡片内，不合并成一条横条。
- 结尾只写一句话总结 + 已学链，不罗列术语。
- 场景 `overflow:hidden`，stage 宽 `min(820px,92vw)`，SVG 高 300–360，避免 1200×780 溢出。
